# Assumptions and scope

The implemented source is arXiv:2406.08250v1. The journal version has not been
obtained or compared. Source hashes identify downloaded PDF, HTML and TeX.
The original effective prescription is treated as a phenomenological source
in Einstein's equation, not as a derived covariant LQC action.

Coordinates are (t,r,theta,phi), signature (-,+,+,+), with r an areal radius.
Use r>=r0>0, critical density>0, beta>=0 and constant omega!=-1 for the
published lapse. beta=0 and inverse critical density=0 are formal limits.
The physical meaning and restored dimensions of simultaneous G=c=hbar=1
require an explicit audit; all existing numerical values use the paper's units.

The source assumes isotropic effective pressure. The actual Casimir stress
in a specified quantum boundary-value problem is not independently derived.
No claim of dynamical stability follows from dp_e/d_rho_e alone.
The redshift normalization fixes a time-coordinate scale; matching to an
exterior requires a separate normalization and junction analysis.

The Branch B result limits physical interpretation of all downstream plots.
A faithful expression reproduction remains meaningful as arithmetic and
geometry. It cannot validate the stated effective isotropic solution.

No human scientific review has occurred. No novelty claim is established.
